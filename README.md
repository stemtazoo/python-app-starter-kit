# Python App Starter Kit

AIと一緒に、小さなPython業務改善アプリを完成させるための初心者向けスターターキットです。

> [!IMPORTANT]
> **パスワード、APIキー、個人情報、実際の業務データを、AIとのチャットへ入力しないでください。**  
> コードやエラーを相談するときは、`YOUR_PASSWORD`、`user@example.com`などの架空の値へ置き換えます。詳しくは[チャット・データ取り扱いガイド](docs/security-and-privacy.md)を確認してください。

## はじめて使う方へ

このリポジトリはアプリ本体ではなく、AIに「初心者をどのように支援するか」を伝えるスターターキットです。次のいずれかの方法で使い始められます。

### 方法1：リポジトリのリンクをAIへ伝える

GitHubを参照できるAIでは、この方法が最も簡単です。新しいチャットで、次の文章を送ります。

```text
次のリポジトリにあるREADME.md、AGENTS.md、および
AGENTS.mdから案内されているdocs内の文書を読んでください。

https://github.com/stemtazoo/python-app-starter-kit

これらの方針に従って、初心者向けにアプリ制作を支援してください。
最初から詳細な仕様を作り込まず、小さな試作品から始めてください。
```

AIがリンク先を読めないと答えた場合は、方法2を使います。

### 方法2：ファイルをダウンロードしてチャットへ添付する

1. このページ上部の **Code** ボタンを押します。
2. **Download ZIP** を選びます。
3. ダウンロードしたZIPファイルを展開します。
4. 新しいチャットへ、次のファイルを添付します。
   - `README.md`
   - `AGENTS.md`
   - `.gitignore`
   - `docs`内のMarkdownファイル
5. 下の「最初の依頼文」を送ります。

利用しているチャットがZIPファイルの読み込みに対応している場合は、展開せずZIPファイルを添付しても構いません。読み込めない場合は、上記のファイルを個別に添付してください。

### 方法3：ローカルのAIコーディングツールで使う

1. **Code → Download ZIP** でダウンロードします。
2. ZIPファイルを展開します。
3. 展開したフォルダを、作りたいアプリの名前へ変更します。
4. そのフォルダをAIコーディングツールで開きます。
5. 「最初にAGENTS.mdを読んで、この方針に従ってください」と伝えます。

この方法なら、AIがファイルを直接作成・変更できます。元のリポジトリはPublic設定のため、実際の業務データや個人情報を元のリポジトリへ追加しないでください。

### 最初の依頼文

分かる範囲だけ記入すれば十分です。空欄がある場合、AIは実装に大きく影響する質問から1つずつ確認します。

```text
添付した文書、または案内したリポジトリの方針に従って、
小さな業務改善アプリの制作を支援してください。

困っていること：
自動化したい作業：
入力と出力：
最初の完成条件：

プログラム初心者にも分かるように説明し、
今回の完成までの進捗も示してください。
```

既存のコードやエラー画面を追加で共有するときは、パスワード、APIキー、個人情報、社内URL、実際の業務データが含まれていないか、送信前に確認してください。

このリポジトリでは、最初から詳細な仕様を作り込むのではなく、次の流れを大切にします。

1. 困りごとと最初の完成条件を決める
2. 最小限の試作品を作る
3. 実際に動かして確認する
4. 必要な部分だけ改善する
5. 分かったことをREADMEや設計メモへ残す

> Prototype first, document as you learn.  
> まず試作品を作り、分かったことを後から記録する。

初心者がセットアップで迷わないよう、仮想環境は標準では使用せず、利用者から指示があった場合にだけ使用します。

Windows向けアプリでは原則として`start.bat`を用意し、ダブルクリックで起動できる状態を目指します。

エラーが出たときは、コードを何度も変更する前に、まずエラー画面のスクリーンショットを撮ってAIへ伝えます。共有前に、個人情報や秘密情報が映っていないか確認します。

また、起動前のPython・必須ファイルの確認、変更を元へ戻せる準備、今回の完成条件を基準にした進捗表示を標準とします。

## ドキュメント

- [AGENTS.md](AGENTS.md)  
  AIがアプリ制作を支援するときに守る、具体的な進め方と判断基準です。
- [開発原則](docs/development-principles.md)  
  初心者が途中で迷わず、小さな業務改善アプリを完成させるための基本方針です。
- [推奨ディレクトリ構成](docs/project-structure.md)  
  Pythonコード、設定、文書、テスト、業務データの標準的な置き場所です。
- [チャット・データ取り扱いガイド](docs/security-and-privacy.md)  
  AIとのチャットやGitHubへ入力してはいけない情報と、安全な置き換え方です。
- [コードを手作業で反映する方法](docs/copy-paste-guide.md)  
  チャットに表示されたコードの変更場所を確認し、自分のPCへ安全に貼り付ける方法です。
- [エラーが出たときの進め方](docs/troubleshooting.md)  
  エラー画面のスクリーンショットを起点に、AIと一つずつ確認する方法です。

## 参考資料

このスターターキットは、次の資料を参考にしています。ただし、初心者が小さな業務改善アプリを早く完成させる目的に合わせて、手順や構成を簡略化しています。

- [GitHub Spec Kit](https://github.com/github/spec-kit)  
  仕様、計画、タスク、実装をつなげるSpec-Driven Developmentの考え方を参考にしています。本リポジトリでは、試作までの負担を減らすため「小さく試作してから記録する」流れへ調整しています。
- [Custom instructions with AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md)  
  Codexが`AGENTS.md`を読み込む範囲や、階層ごとに指示を分ける方法を確認できます。
- [PyPA sampleproject](https://github.com/pypa/sampleproject)  
  Pythonプロジェクトで使われる基本的なファイルやディレクトリ構成の参考です。
- [srcレイアウト対フラットレイアウト](https://packaging.python.org/ja/latest/discussions/src-layout-vs-flat-layout/)  
  Pythonコードを`src/`へ分ける場合の利点と注意点を学べます。本リポジトリでは、事前インストールを必須にしない形へ簡略化しています。
- [pip User Guide：Requirements Files](https://pip.pypa.io/en/stable/user_guide/#requirements-files)  
  `requirements.txt`を使って必要なライブラリをインストールする方法の公式資料です。
- [Python公式ドキュメント：`__main__`](https://docs.python.org/ja/3/library/__main__.html)  
  Pythonプログラムの起動地点と、`if __name__ == "__main__":`の考え方を確認できます。
- [GitHub公式 Python.gitignore](https://github.com/github/gitignore/blob/main/Python.gitignore)  
  PythonプロジェクトでGitHubへ登録しないファイルを判断するための基準です。
