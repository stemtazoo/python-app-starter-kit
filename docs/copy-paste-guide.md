# コードを手作業で反映する方法

この文書は、GitHubやCodexによる直接編集を使わず、AIとのチャットに表示されたコードを自分のPCへコピーして反映する人向けのガイドです。

## 基本方針

初心者が手作業でコードを反映する場合は、**安全に全文を確認できるなら、対象ファイル全体を置き換える方法を第一候補**とします。

部分的な貼り付けは、貼り付け位置、インデント、古いコードの残りなどでミスが起きやすいためです。

ただし、AIが現在のファイル全文を確認できていない場合や、利用者独自の変更が含まれている可能性がある場合は、推測で「完全版」を作ってはいけません。GitHub、Codex、IDE連携などで現在のファイルを再取得できる場合は再取得し、できない場合は利用者に現在のファイル全文を共有してもらってから全体置換用のコードを作成します。

## AIの説明に必要な4項目

AIがコードの追加や修正を提案するときは、必ず次の順番で説明します。

1. **対象ファイル**：どのファイルを開くか
2. **変更方法**：新規作成、全体置換、部分置換、追加のどれか
3. **変更場所**：どの関数やコードを目印にするか
4. **確認方法**：保存後に何を実行し、何が表示されれば成功か

「適切な場所へ追加してください」「このあたりを修正してください」だけで終わらせません。

## 変更方法の優先順位

手作業で反映する場合は、原則として次の順番で検討します。

1. **新規ファイル**：省略のない完全な内容を出す
2. **安全に全文を確認できる既存ファイル**：ファイル全体の置き換えを優先する
3. **全文置換で利用者独自の変更を失うおそれがあるファイル**：現在の全文を確認してから全体置換する
4. **非常に長いファイルや、全文置換より部分変更の方が明らかに安全な場合**：変更前と変更後を完全なコードブロックで示して部分置換する

行数だけで機械的に判断せず、初心者が迷いにくく、既存コードを失う危険が少ない方法を選びます。

## AIが現在の全文を確認できていない場合

AIは、以前の会話で一度見たファイルについても、長い会話の途中で全文を正確に保持できていない可能性があります。

そのため、全体置換用のコードを出す直前に、AIは対象ファイルの現在の全文を確実に確認できているか判断します。

- GitHub、Codex、IDE連携、ファイル添付などで現在のファイルを取得できる場合は、最新の内容を再取得する
- 取得できない場合は、利用者に対象ファイルの全文を共有してもらう
- ファイルが長い場合は、ファイルそのものを添付してもらう方法を優先する
- 「前に見たから大丈夫」と推測して全文を再構成しない
- `...`、記憶から補った処理、存在確認できていない関数を含む状態で「完全版」と呼ばない

現在の全文を確認できない場合は、全体置換を中止し、必要最小限の部分変更へ切り替えることもできます。その場合も、変更前のコードが現在のファイルと一致することを確認してから案内します。

## 変更前に戻れる状態を作る

コードを変更する前に、問題が起きたときの戻し方を確認します。

- Gitを使っている場合：変更前をコミットするか、現在の差分を確認する
- Gitを使っていない場合：変更するファイルを `main.py.backup` のような別名でコピーする
- 複数ファイルを変更する場合：1ファイルずつ変更して、その都度確認する
- 正常に動くことを確認するまで、バックアップを削除しない

AIは修正コードと一緒に、次のように戻し方も示します。

```text
元に戻す方法：
1. 変更したmain.pyを閉じます。
2. main.pyをmain_failed.pyへ名前変更します。
3. main.py.backupをmain.pyへ名前変更します。
4. start.batをダブルクリックして、元の動作に戻ったか確認します。
```

バックアップにも秘密情報や実際の業務データを含めないよう注意します。

## 新しいファイルを作る場合

次のように、保存先と完全な内容を示します。

```text
対象ファイル：src/config.py
変更方法：新しいファイルを作成
```

続くコードブロックには、ファイルへそのまま貼り付けられる完全な内容を掲載します。途中を `...` で省略しません。

## ファイル全体を置き換える場合

初心者が手作業で反映する場合は、現在の全文をAIが確認できており、利用者独自の変更を失う危険がないなら、この方法を優先します。

次のように明示します。

```text
対象ファイル：main.py
変更方法：ファイル全体を置き換え

手順：
1. main.py を main.py.backup としてコピーします。
2. 元の main.py を開きます。
3. Ctrl+A で全体を選択します。
4. 下のコードを貼り付けます。
5. Ctrl+S で保存します。
```

続くコードブロックには、省略のないファイル全文を掲載します。

置き換える前に、現在のファイルに自分で加えた変更がないか確認します。AIが現在の全文を確認できていない場合は、利用者に全文を共有してもらうか、利用可能な連携機能で再取得してから完全版を作成します。

Gitを使っていない場合や、元に戻せるか不安な場合は、次のような名前でバックアップを作ります。

```text
main.py.backup
```

## ファイルの一部を置き換える場合

全体置換より部分置換の方が安全な場合に使用します。

行番号だけではなく、関数名や既存コードを目印として示します。行番号はコードを変更するとずれるためです。

### 変更前

```python
def calculate_total(values):
    return sum(values)
```

### 変更後

```python
def calculate_total(values):
    if not values:
        return 0
    return sum(values)
```

説明は次のようにします。

```text
対象ファイル：src/core.py
変更方法：部分置換
探す場所：calculate_total関数

「変更前」のコードを探し、同じ範囲を「変更後」のコードへ置き換えてください。
```

変更前のコードが見つからない場合は、似た場所へ推測で貼り付けず、現在の該当部分を個人情報などを伏せてAIへ確認します。

## コードを追加する場合

追加だけで済む場合でも、短いファイルで安全に全文を確認できるなら全体置換を優先します。

部分追加を使う場合は、追加位置の前後にあるコードを目印として示します。

```text
対象ファイル：src/ui.py
変更方法：コードを追加
追加場所：setup_window関数の直後、run_app関数の直前
```

「ファイルの最後」「クラスの中」のような曖昧な表現だけにせず、関数名やクラス名を併記します。

Pythonでは字下げもコードの一部です。クラスや関数の中へ追加するときは、必要な空白の数が分かるコードブロックを示します。

## 複数ファイルを変更する場合

一度にすべて貼り付けさせず、原則として次の順番で案内します。

1. 1つ目のファイルを変更する
2. 保存する
3. エラーがないか確認する
4. 次のファイルへ進む
5. 最後にアプリ全体を確認する

各ファイルについて、対象ファイルと変更方法を繰り返し明記します。

## 差分表示の注意

初心者がコピーするコードには、次のような差分記号を含めません。

```diff
- old_code()
+ new_code()
```

`+`や`-`をコードの一部として貼り付けてしまう可能性があるためです。

変更点を説明するときは、「変更前」と「変更後」を別々のコードブロックで示します。

## コピーできるコードの条件

貼り付け用のコードは次を満たすようにします。

- `...`や「ここに処理を書く」など、実行できない省略を含めない
- 必要な `import`を含める
- 引用符やかっこが閉じている
- Pythonの字下げが正しい
- パスワード、APIキー、個人情報を含めない
- PC固有のパスは、設定値または架空の例にする
- 変更してよい値にはコメントや説明を付ける
- 全体置換と案内する場合は、AIが現在のファイル全文を確認済みである

## 保存後の確認

コードを貼り付けた後は、次を順番に確認します。

1. ファイルを保存する
2. エディタに赤い波線などが出ていないか確認する
3. 指定された起動方法で実行する
4. 期待する結果になるか確認する
5. エラーが出た場合は、コードを続けて変更せず、秘密情報を確認したうえでエラー画面のスクリーンショットを共有する
6. 解決しない場合は、案内された方法で直前の状態へ戻す

Windows向けアプリに `start.bat`がある場合は、まず `start.bat`をダブルクリックします。開発者向けの確認が必要な場合は、READMEに記載されたコマンドを使います。

## AIが使用する回答形式

手作業での反映が必要で、全体置換が安全な場合、AIは原則として次の形式で回答します。

```markdown
## 変更1

対象ファイル：src/core.py  
変更方法：ファイル全体を置き換え

### 手順

1. src/core.py を src/core.py.backup としてコピーします。
2. 元の src/core.py を開きます。
3. Ctrl+A で全体を選択します。
4. 下のコードを貼り付けます。
5. Ctrl+S で保存します。

### 貼り付けるコード

（省略のないファイル全文）

### 確認方法

1. start.batをダブルクリックします。
2. 期待する結果になれば成功です。
```

全体置換が安全でない場合だけ、次のように部分置換を使用します。

```markdown
## 変更1

対象ファイル：src/core.py  
変更方法：部分置換  
探す場所：calculate_total関数

### 変更前

（現在のコード）

### 変更後

（そのまま貼り付けるコード）

### 確認方法

1. ファイルを保存します。
2. start.batをダブルクリックします。
3. 合計が画面に表示されれば成功です。
```

利用者が直接編集を依頼できるGitHub、Codex、IDE連携などを使用している場合は、この形式を毎回強制する必要はありません。ただし、変更したファイルと確認方法は最後に伝えます。
